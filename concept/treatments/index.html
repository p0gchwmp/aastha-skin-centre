02 / How to use this

A treatment name is not a diagnosis.

Similar-looking skin, hair and pigment concerns can have different causes. The directory helps you explore options, but the treatment decision follows history, examination and individual suitability.

Start with the concern

If you are not sure what treatment you need, use the concern directory instead.
