AASTHA COMPLETE PROFESSIONAL WEBSITE REBUILD V20

This is a consolidated full-site rebuild. It is not another small cleanup layer.

It addresses the exact issues shown in the supplied PDF exports:
- dark-mode header and CTA contrast;
- loose paragraphs that should be real bullet lists;
- very long treatment pages that feel like raw documents;
- giant "On this page" blocks;
- public editorial/template instructions;
- weak inner-page presentation;
- the Blog link/page opening problem;
- overlong Contact content;
- inconsistent sidebars and final CTAs.

WHAT IT DOES ACROSS THE COMPLETE WEBSITE

1. Applies one last-loaded professional theme to every HTML page.
2. Gives every inner page the same premium hero, typography, spacing and card system.
3. Converts runs of short raw paragraphs into semantic bullet grids.
4. Makes list items such as Teenage acne, Adult acne, Melasma, Hair fall and Fungal infection clickable where a matching page exists.
5. Groups body content into polished sections.
6. Uses collapsible detail panels for secondary content on unusually long pages.
7. Replaces the oversized automatic table of contents with compact topic chips.
8. Replaces all sidebars with one readable consultation card.
9. Rebuilds the Blog page with real, working patient-guide links.
10. Adds a Render /blog -> /blog/ redirect without creating a duplicate canonical page.
11. Rebuilds the Contact page as action cards, clinic cards and a working WhatsApp enquiry form.
12. Repairs the duplicate applyGlobalFacts function declaration in site.js.
13. Adds a complete dark-mode contrast system for navigation, buttons, cards, forms, CTAs, disclaimers and article content.
14. Backs up each changed HTML file before writing it.
15. Runs sitemap, QA, predeployment checks and clean dist build.

HOW TO APPLY

1. Close the existing local preview server.
2. Extract this ZIP.
3. Copy the complete extracted contents into the main GitHub repository folder.
4. Choose Replace/Overwrite.
5. Run:

   23_Apply_Complete_Professional_Site_v20.bat

6. Wait for:

   SUCCESS: Complete professional website rebuild, QA and clean build completed.

7. Run:

   24_Preview_Complete_Professional_Site.bat

Review Home, Blog, Contact, Conditions, Treatments, Acne Treatment and two other long treatment pages in both light and dark mode before pushing.
