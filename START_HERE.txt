THE SITEMAP ERROR

The blog page was indexable but had not yet been added to sitemap.xml.
The new sitemap builder scans the current website and automatically adds all
indexable canonical URLs, including:

    https://www.aasthaskincentre.in/blog/

The updated QA, predeployment and deployment-build tools rebuild the sitemap
before continuing, so the same error should not return.

CLEARING THE CLUTTER

Run:
    12_Clean_Project_View.bat

It:
- moves documentation into _project-docs;
- moves obsolete tools into _legacy-tools;
- hides technical working folders;
- hides the individual BAT files;
- leaves Aastha_Tools.bat visible as the main control centre.

No website pages, imported content, reports or backups are deleted.

To see everything again:
- open Aastha_Tools.bat and choose option 16; or
- run 13_Show_All_Project_Files.bat.
